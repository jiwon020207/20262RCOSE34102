## Study Notes

1. An operating system manages computer hardware and software.
2. A process is a running program.
3. A thread is an execution unit.
4. The CPU executes instructions.
5. RAM stores active data.
6. Scheduling selects processes.
7. FCFS is a scheduling algorithm.
8. Round Robin uses time slices.
9. Deadlock can block processes.
10. Virtual memory uses address mapping.
